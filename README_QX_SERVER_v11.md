## ما الجديد في v11.0 (طلب المستخدم)

1. **استخدام مكتبة FastAPI:**
   - الواجهة تعمل على `http://127.0.0.1:8000` عبر FastAPI + uvicorn.
   - المتصفح يفتح تلقائياً عند بدء التشغيل.

2. **عند التشغيل لا يسأل عن أي عملة إطلاقاً:**
   - الكونسول يسأل فقط عن **البريد الإلكتروني** و**كلمة المرور** (نفس طريقة الدخول الأصلية دون أي تغيير).
   - لا يوجد سؤال عن العملة أو الفريم أو عدد الأيام.
   - التعرف على النطاق تلقائي (بنغلاديش → `market-qx.info` / أي دولة أخرى → `quotex.com`).

3. **بعد الدخول يجلب قائمة العملات الكاملة ويعرضها في الواجهة:**
   - اسم كل عملة + نسبة الدفع % + نسبة التيربو % + أرباح 1 دقيقة و5 دقائق.
   - حالة كل عملة: **مفتوح** (أخضر) أو **مغلق** (أحمر).
   - التحديث تلقائي كل 15 ثانية في الواجهة (بيانات الخادم تتجدد كل 60 ثانية).
   - بحث فوري + فلتر "المفتوحة فقط" + عداد النتائج.
   - الترتيب: المفتوحة أولاً ثم حسب نسبة الدفع الأعلى.

4. **كما هو دون تغيير:**
   - طريقة تسجيل الدخول (نفس آلية SSID/بريد + كلمة المرور حرفياً).
   - محرك جلب الشموع (1000 شمعة) موجود في الملف كما هو، لكنه لا يُشغَّل تلقائياً عند البدء لأن البرنامج لا يسأل عن أي عملة.
   - التعرف الجغرافي على النطاق، ومحرك الاتصال/إعادة الاتصال/المراقبة الصحية.

## طريقة التشغيل

```bash
# 1) تثبيت المتطلبات
pip install -r requirements_qx_server.txt

# 2) تشغيل البرنامج
python qx_server_v11.py
```

- البرنامج يسأل: البريد → كلمة المرور → يدخل.
- يتعرف على دولتك تلقائياً ويختار النطاق الصحيح.
- يفتح المتصفح على `http://127.0.0.1:8000` ويعرض قائمة العملات (إذا كان المنفذ مشغولاً ينتقل تلقائياً للمنفذ التالي ويطبع الرابط في الكونسول).
- اترك الترمينال مفتوحاً. للخروج: Ctrl+C.

## ملفات الواجهة (API)

| المسار | الوظيفة |
|---|---|
| `GET /` | صفحة الواجهة العربية (RTL، ثيم داكن) |
| `GET /api/assets` | قائمة العملات الكاملة: اسم + دفع % + تيربو % + مفتوح/مغلق |
| `GET /api/status` | حالة الاتصال + النطاق + البلد + الحساب (مخفي جزئياً) |

- لقطة كاملة تُحفظ أيضاً في `qx_assets_payouts.json` بجانب الملف وتتحدث دورياً.
