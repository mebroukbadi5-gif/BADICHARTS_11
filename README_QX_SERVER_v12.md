# BADICHARTS_11 — v12.0 من خادم Quotex (عرض في الترمينال)

**الملف: [`qx_server_v12.py`](qx_server_v12.py)** — افتحه واضغط زر تحميل (Download raw file).

---

## ما الجديد في v12.0

1. **نزع واجهة HTML بالكامل** (بطلب المستخدم):
   - لا يوجد FastAPI ولا uvicorn ولا صفحة متصفح.
   - العرض كله في **الترمنال** مباشرة.

2. **إصلاح جلب قائمة العملات (سبب المشكلة السابقة):**
   - السبب: خادم Quotex يرد على طلب `instruments/get` على **مرحلتين**:
     - المرحلة 1: رسالة تحكم تحمل `placeholder` فقط (`451-["instruments/list",{...,"_placeholder":true}]`).
     - المرحلة 2: إطار منفصل (غالباً binary) يحتوي JSON القائمة الفعلية.
   - النسخ السابقة كانت تعالج الصيغة المضمّنة فقط (القائمة داخل نفس الرسالة)، ولذلك **لم تُخزَّن القائمة أبداً** وظهرت فارغة.
   - الآن يطبّق الكود المسارين معاً (نفس سلوك المكتبة الرسمية pyquotex)، ومُختبر باختبارات وحدة ناجحة على جميع الصيغ.

3. **العرض في الترمينال:**
   - جدول كامل يُطبع فوراً بعد الدخول: العملة / الاسم / نسبة الدفع % / التيربو % / أرباح 1د و5د / الحالة (OPEN مفتوح بالأخضر، CLOSED مغلق بالأحمر).
   - الترتيب: المفتوحة أولاً ثم حسب نسبة الدفع الأعلى.
   - عند أي تغيير (دفع أو حالة) يُعاد طباعة الجدول تلقائياً كل 60 ثانية مع وقت التحديث.
   - عند فشل الجلب يعيد المحاولة 3 مرات قبل الدورة التالية.
   - لقطة كاملة تُحفظ في `qx_assets_payouts.json` بجانب الملف.

4. **كما هو دون تغيير:**
   - عند التشغيل يسأل فقط عن **البريد** و**كلمة المرور** (نفس طريقة الدخول الأصلية حرفياً).
   - النطاق تلقائياً: بنغلاديش → `market-qx.info` / أي دولة أخرى → `quotex.com`.
   - محرك جلب الشموع (1000 شمعة) موجود في الملف كما هو، ولا يُشغَّل تلقائياً (البرنامج لا يسأل عن أي عملة).

## طريقة التشغيل

```bash
# 1) تثبيت المتطلبات
pip install -r requirements_qx_server.txt

# 2) تشغيل البرنامج
python qx_server_v12.py
```

- البرنامج يسأل: البريد → كلمة المرور → يدخل.
- يتعرف على دولتك تلقائياً ويختار النطاق الصحيح.
- خلال ثوانٍ يطبع جدول العملات الكامل في الترمينال ويحدّثه تلقائياً.
- للخروج: Ctrl+C.

## المتطلبات
