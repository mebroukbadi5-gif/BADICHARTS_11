# BADICHARTS_11 — تحديث v10.0 من خادم Quotex

تم رفع النسخة النهائية المعدّلة هنا مباشرة حتى تستطيع تحميلها من غيت هاب:

**الملف: [`qx_server_v10.py`](qx_server_v10.py)** — اضغط على اسم الملف ثم اضغط زر تحميل (Download raw file) أو أيقونة السهم أعلى يمين محتوى الملف.

---

## التعديلات المتفق عليها في هذه النسخة (v10.0)

1. **اختيار النطاق جغرافياً (تلقائي):**
   - بنغلاديش (BD) → `market-qx.info`
   - أي دولة أخرى → `quotex.com` (النطاق الرسمي العالمي)
   - التعرف على الدولة يتم تلقائياً عند تسجيل الدخول، ويمكن أيضاً اختيار النطاق يدوياً من القائمة.

2. **قائمة العملات الكاملة + نسبة الدفع + الحالة:**
   - يجلب جميع الأزواج المتاحة مع نسبة الدفع (payout) لكل زوج.
   - يعرض حالة كل زوج: مفتوح / مغلق.
   - يُحفظ اتساقاً في ملف `qx_assets_payouts.json` بجانب الملف ويتحدث دورياً أثناء التشغيل.

3. **كل الفريمات المدعومة:**
   - `S5` ثواني ×5 — `S10` ×10 — `S15` ×15 — `S30` ×30 (تُبنى محلياً من التيكات الحية)
   - `M1` ×1 — `M2` ×2 — `M3` ×3 — `M5` ×5 — `M10` ×10 — `M15` ×15 — `M30` ×30
   - `H1` ×1 ساعة — `H4` ×4 ساعات — `D1` ×1 يوم

4. **نزع Flask بالكامل:**
   - لا يوجد سيرفر ويب ولا لوحة متصفح في هذه النسخة.
   - القناة الوحيدة للمخرجات: ملفات MT4 `.hst` + ملف `qx_assets_payouts.json` + مخرجات الكونسول.

5. **كما هو دون تغيير (بدون أي تعديل):**
   - طريقة تسجيل الدخول (نفس آلية SSID/بريد + كلمة المرور كما في الكود الأصلي).
   - جلب **1000 شمعة** تاريخية (نفس الطريقة الأصلية بالضبط).

## طريقة التشغيل

```bash
# 1) تثبيت المتطلبات
pip install -r requirements_qx_server.txt

# 2) تشغيل البرنامج
python qx_server_v10.py
```

- عند التشغيل يتعرف البرنامج على دولتك تلقائياً ويختار النطاق الصحيح.
- اختر العملة، الفريم، وعدد الأيام (أو اضغط Enter للافتراضي: 1000 شمعة).
- الملفات الناتجة تُكتب في مجلد `HST` بجانب الملف وتُحدّث لحظياً — افتحها من MetaTrader أو أي برنامج يقرأ صيغة `.hst`.
